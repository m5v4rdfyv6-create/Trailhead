TRAILHEAD PWA

Upload every file in this folder to a GitHub repository.

GitHub Pages:
1. Repository Settings → Pages.
2. Deploy from main branch / root.
3. Open the Pages URL.

iPhone:
Open the deployed site in Safari → Share → Add to Home Screen.

Desktop:
Open the deployed site in Chrome/Edge and use Install App.

Your tasks, streak, and quick picks are stored locally on the device/browser.
